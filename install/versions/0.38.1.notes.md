## v0.38.1 — 2026-09-15

[Compare v0.38.0...v0.38.1](https://github.com/kenlin8827/opencode-prime/compare/v0.38.0...v0.38.1)

### ✨ Installer quality of life

- **Local-checkout detection** — running `install.ps1` / `install.sh` from inside a repo checkout (or with the repo in the current directory) now executes the in-repo installer directly instead of downloading a release. An explicit `-Version` / `-v` still takes the download path.
- **Automated Bun install** — when the Bun runtime is missing, the installer now offers to install it via the official `bun.sh/install` script (prompt, or non-interactive with `-Yes` / `-y`); skipping stays harmless, everything except the interactive TUI still works on Node.js.

### ✨ TUI without a Bun-hosted CLI

- `ocp dashboard` / `ocp wizard` and friends now work when the CLI itself runs under **Node.js**: the OpenTUI child process is spawned via `node:child_process` with a resolved Bun (`BUN_INSTALL`, `~/.bun/bin`, or PATH). When no usable Bun exists, the error message prints the exact one-line install command for your platform.

### 🐛 Fixes

- **New presets now reach existing installs** — the "ship once, then user owns `providers/`" rule previously meant presets added in a new release were never seeded on upgrade. Seeding now baselines on the *installed* version's manifest (falling back to the historical union when that manifest has been compacted away): a preset new relative to what this machine actually has is seeded once, existing same-named user files are never overwritten, and a same-version reinstall never resurrects a preset the user deleted.
