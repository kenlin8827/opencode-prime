## v0.43.1 — 2026-09-24

[Compare v0.43.0...v0.43.1](https://github.com/kenlin8827/opencode-prime/compare/v0.43.0...v0.43.1)

### 🛠️ `/dev-deep` checkpoints are per-task (parallel-run safe)

v0.43.0 wrote a single `.ocp/dev-deep-state.md` — two concurrent (or interleaved) `/dev-deep` runs in one project would clobber each other's state, and `--resume` could not tell tasks apart. Checkpoints now live at **`.ocp/dev-deep/<slug>.md`** (one file per task; slug derived from the requirement's subject, announced at planning):

- `--resume=<slug>` resumes a specific task; bare `--resume` auto-picks the single checkpoint or lists several (requirement + timestamp + progress) to choose from.
- Same-slug ACTIVE checkpoint without `--resume` → guard question (resume / overwrite / abort) — never a silent clobber.
- Checkpoint frontmatter gains `slug` + `status` (`running | stopped | completed`); the guard only fires on non-completed states.

**`.ocp/.gitignore` contract**: the v0.43.0 line `dev-deep-state.md` becomes the directory entry `dev-deep/` (still seven lines). Projects that already received the 0.43.0 line: heal appends `dev-deep/`; the old line stays inert (nothing writes to that path anymore).

### 🔖 Why a patch bump

Defect fix to the v0.43.0 feature — no new surface; single-run behavior is unchanged apart from the checkpoint path.
