## v0.36.1 — 2026-09-14

[Compare v0.36.0...v0.36.1](https://github.com/kenlin8827/opencode-prime/compare/v0.36.0...v0.36.1)

### 🛡️ tgrep output budget (context safety)

- **Detail refusal** — `locations`/`content` requests whose summary exceeds the 2,000-row output budget are refused with `complete: false` and the true totals instead of flooding the caller's context; the refusal text carries narrowing guidance the caller can act on.
- **Char budget** — materialized detail output past 150,000 chars (long lines, mid-search growth) is refused the same way.
- **Summary truncation** — default `path:count` output past 2,000 files is truncated with an explicit omission marker (`complete: false`); metadata totals stay complete.

### 🔧 Hardening

- **Relative `path` anchoring fix** — `tgrep_search` relative `path` values (and the `.` default) now anchor to the project directory instead of the host process's launch cwd; searches no longer silently miss files when opencode is launched from outside the repo root.
- Detail metadata no longer reuses summary totals when the detail run finds no matches (two-spawn race).
- Request-log write failures now warn instead of failing silently.
- Installer tolerates `null` tool entries in user-edited options files.
