## v0.35.0 — 2026-09-13

### ⚠️ Path migration (ADR 0004) — ACTION REQUIRED

Project OCP artifacts moved `.opencode/` → `.ocp/` (config `.ocp/ocp.json`, memory, handoffs, logs, style overrides). **Run `/project init` or open the project wizard / `/project sync` once after upgrading** — without it, project switches read defaults (no runtime fallback by design). The migration is one-shot, idempotent, and visible in the wizard/init report: it copies switch keys (removing them from legacy configs while preserving platform keys) and relocates memory/handoff/style files. Global `~/.config/opencode/ocp.jsonc` is renamed to `ocp.json` automatically by the installer (XDG-aware; both-present collision keeps both and `ocp.json` wins). Downgrade to older versions is lossy: they don't read `.ocp/`.

[Compare v0.34.0...v0.35.0](https://github.com/kenlin8827/opencode-prime/compare/v0.34.0...v0.35.0)

### 🎯 Highlights

- 📦 **`.ocp/` path contract (ADR 0004)** — `.opencode/` is now 100% OpenCode platform territory (config, `themes/`, discovery dirs); everything OCP owns lives in `<project>/.ocp/`: `ocp.json` (OCP switch keys, strict JSON), `memory/{public,private}.md`, `handoffs/`, `logs/`, `dev-ultra-state.md`, md-to-pdf/docx style overrides, and a self-managed `.ocp/.gitignore`. OCP never writes into platform files anymore.
- ⚙️ **`OCP_PROJECT_DIR`** — rename the project OCP directory if `.ocp` collides with other tooling. Project-relative only: absolute or `..`-escaping values are invalid and silently fall back to `.ocp`.
- 🧭 **One-shot init migration** — the project wizard migrates at OPEN (before switch detection), `/project init` and the repurposed `/project sync` run the same idempotent migration; reports surface what moved, warnings never abort the flow.
- 🛡️ **Global config hardening** — `ocp.json` (pure JSON; JSONC-tolerant reads kept), installer performs the legacy `ocp.jsonc` rename with XDG-aware destination and wrong-base rescue; collision keeps both files.
- 🔧 **Fixes** — wizard no longer resets migrated switches to defaults (regression-pinned in the structural gate); Mermaid rendering resolves `playwright` correctly under bun temp-dir workers; repaired two parse-broken checks that had silently disabled `test-all.ps1` since its last edit.
- 🧾 **`@script:` tool installers** — the escape-prone PowerShell/shell one-liners that install and upgrade tgrep, ripgrep and rtk are now real reviewable `.sh`/`.ps1` files under `install/scripts/tools/`, referenced from `tools.jsonc` as `@script:<name>` and resolved platform-arch → platform → bare. Mirror-first (`OCP_RELEASE_MIRROR`) / official-fallback URL handling lives in the scripts themselves.
- 🚧 **External-binary refusal contract** — the @script installers refuse (exit 2) to overwrite a binary that lives outside the user profile (owned by another package manager) and print how to update it instead; `ocp update` reports those rows as `↷ left as-is (managed outside ocp)` — and only for @script-managed tools, so an unrelated exit-2 (a package manager or a broken `curl | bash` download) still counts as a real failure. The probe marks such rows `externally managed` and stops offering them as pending updates.
- 🔌 **luvus upgrade hooks** — on Windows the running luvus server locks `luvus.exe`; `pre_upgrade` stops the background server before the binary swap and `post_upgrade` restarts it (post runs even on a failed upgrade, so the server always comes back). Locked-exe handling in the tool scripts uses the rename-to-`.old` pattern with loud failure when even the rename is impossible.
- 🪟 **`windowsHide` fixes** — `ocp-cli.js` probes, the detached `herdr server` launch, and `herdr-recovery` no longer flash (or leave behind) a console window on Windows; closing that stray window used to kill the detached server and every attached TUI with it.
- 🎨 **Sidebar status restyle** — status rows use the same `•` bullet as the MCP group with colour carried by the dot only; values render in title case (`On · Empty`, `Ready`, `Off`) in muted text instead of ALL-CAPS colours; the blank gap above the "OCP project" header is gone, matching the tight MCP/LSP stacking. Badge builders keep their ALL-CAPS contract — only the display casing changed.

### 📦 Path contract — what moved where

| Scope | Old | New |
|---|---|---|
| Project switches | `.opencode/opencode.jsonc` / root `opencode.jsonc` | `.ocp/ocp.json` (strict JSON) |
| Memory | `.opencode/memory/` | `.ocp/memory/` |
| Handoffs / logs / state | `.opencode/handoffs|logs|dev-ultra-state.md` | `.ocp/…` |
| Style overrides | `.opencode/md-to-*.{css,docx}` | `.ocp/…` |
| Global user config | `~/.config/opencode/ocp.jsonc` | `~/.config/opencode/ocp.json` |
| Platform (unchanged) | `opencode.jsonc` files, `themes/`, `agent|command|plugin|skill/` | stay under `.opencode/` |

See `docs/adr/0004-ocp-path-contract.md` for the full contract and `docs/reviews/2026-09-12-ocp-path-contract.md` for the gate record.
