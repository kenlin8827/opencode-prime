### ✨ OmniRoute gateway profile

- **`router/omniroute-auto`** — bundled profile for the self-hosted OmniRoute gateway, mapping each tier to a documented `auto/*` channel: `auto/fast` explores on flash (ship-fast weights), `auto/chat` carries the high-traffic standard tier (balanced default), `auto/coding` codes on pro (quality-first weights), `auto/reasoning:pro` (reasoning-only + premium pool) judges on max, `auto/vision` handles vision (vision-capable pool).
- **`omniroute` provider preset** (`providers/omniroute.json`) — OpenAI-compatible preset listing the gateway's 38 `auto/*` combo models. Credentials come from `OMNIROUTE_BASE_URL` (`https://orouter.agent.byteswim.cn/v1`) and `OMNIROUTE_API_KEY`, or by editing the preset file directly.
