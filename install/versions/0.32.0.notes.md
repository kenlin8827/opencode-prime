## v0.32.0 — 2026-09-10

[Compare v0.31.0...v0.32.0](https://github.com/kenlin8827/opencode-prime/compare/v0.31.0...v0.32.0)

### 🎯 Highlights

- 🎨 **Installer UI rewrite — Solid.js + OpenTUI** — new `install/src/ui/` (app, theme, router, runtime, modal, screens/home, builtin-themes, opencode-theme); replaces the @clack/prompts-based wizard; ships `solid-js` + `@opentui/solid` deps.
- 🪄 **Wizards split into separate commands** — `ocp profile`, `ocp provider`, `ocp project` are now standalone (was monolithic `wizard.ts`).
- 📊 **`ocp usage [--all|.|sessionId]`** — new command for cross-project usage queries.
- 🚀 **Luvus workspace mode** — `ocp tui --luvus` ships as a first-class TUI alternative to Herdr; bundled auto-opencode module + idempotent server start.
- 🧹 **Session: cross-project cleanup** — session cleanup now spans projects.
- 🐛 **Installer fixes** — `ocp` PowerShell arguments preserved; `upgrade` invokes the installer's default action.
- 🎨 **Docs polish** — Teek theme adopted; `opencode-prime.dev` is the canonical docs URL; README shorter with inline UI tour GIFs.

### 🎨 Installer UI rewrite — Solid.js + OpenTUI

- **New UI module** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — full Solid.js OpenTUI under `install/src/ui/`: `app.tsx` (793 lines), `builtin-themes.ts` (1232 lines), `theme.ts`, `tui-host.ts`, `opencode-theme.ts`, `router.ts`, `runtime.ts`, `entry.tsx`, `screens/home.tsx`, `components/modal.tsx`. Replaces the old `@clack/prompts`-driven terminal UI.
- **New dep set** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — `install/package.json` adds `@opencode-ai/plugin@1.18.15`, `@opencode-ai/sdk@1.18.15`, `@opentui/solid@^0.5.4`, `solid-js@1.9.12`. New `install/tsconfig.ui.json` for the UI build.
- **dialog primitives** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — `install/src/ui/tui-host.ts` defines the shared `dialog` type (`select` / `prompt` / `confirm` / `alert`) with the width tiers mirroring OpenCode's `DialogAlert` sizes (60/88/116).
- **Theming** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — built-in theme registry + opencode-theme adapter; themes selectable from the UI and applied to the host terminal.

### 🪄 Wizards split into separate commands

- **`ocp profile`** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — new `install/src/profile-wizard.ts`. Modes: `wizard` / `list` / `apply <name>` / `reset [--yes]` / `usage`.
- **`ocp provider`** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — new `install/src/provider-wizard.ts`. Provider CRUD backed by `plugins/shared/provider-core.ts` and `plugins/shared/profile-core.ts` (also added in this release).
- **`ocp project`** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — `install/src/project-wizard.ts` split out from the old `wizard.ts` (now 15 lines vs the previous 467).
- **Dynamic options schema** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — new `install/src/options-schema.ts` (188 lines): `parseDynamicOptionsSchema` + `updateOptionsJsoncInPlace`. The UI reads and writes `install/options.jsonc` through this schema.

### 📊 `ocp usage`

- **New command** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — `install/src/usage.ts`: `resolveUsageMode(args)` resolves `all` (default, no arg) / `current` (`.`) / `session <id>`. `runUsageCli(repoDir, args)` executes the query.
- **OpenCode SDK v2 client** ([`d44754a`](https://github.com/kenlin8827/opencode-prime/commit/d44754a)) — `createUsageClient` uses `@opencode-ai/sdk` v2 with explicit `OPENCODE_SERVER_URL` and per-request `directory` scoping.

### 🚀 TUI: Luvus workspace mode

- **First-class engine** ([`61cee5f`](https://github.com/kenlin8827/opencode-prime/commit/61cee5f)) — new `tui_mode "luvus"` (`--luvus` flag) wired across bash / PowerShell dispatchers, the TypeScript engine, launcher, options schema, wizard UI, and `tools.jsonc` provisioning.
- **Bundled module** ([`61cee5f`](https://github.com/kenlin8827/opencode-prime/commit/61cee5f)) — `install/luvus-modules/auto-opencode/` (manifest + `index.js`) bundled, linked at install time. Luvus server starts idempotently before a workspace opens; `tab.created` / `pane.created` hooks skip the explicit agent start when one is already running (uses `pane run` instead of `agent start --kind opencode` to dodge Windows PowerShell quoting bugs).
- **CLI i18n** ([`61cee5f`](https://github.com/kenlin8827/opencode-prime/commit/61cee5f)) — status / init / install / uninstall output localized; preferred locale persists across runs; compact select / confirm dialog rendering tightened in the TUI host.
- **Kitty keyboard** ([`61cee5f`](https://github.com/kenlin8827/opencode-prime/commit/61cee5f)) — plain-Esc guards and `Ctrl+A` / `Ctrl+S` now match all three kitty alternate-key report shapes (control byte, disambiguated, alternate).
- **Init semantics** ([`61cee5f`](https://github.com/kenlin8827/opencode-prime/commit/61cee5f)) — only explicit `--init` initializes; a bare `.` is now a stripped no-op; all init logic consolidated in the TS engine ([ADR 0001](https://github.com/kenlin8827/opencode-prime/blob/main/docs/adr/0001-ocp-cli-and-openchamber-activation.md) amended).

### 🧹 Session: cross-project cleanup

- **Spans projects** ([`c5118a8`](https://github.com/kenlin8827/opencode-prime/commit/c5118a8)) — session cleanup now spans projects: per-project retention policies plus a global sweep. Leftover scratch sessions in other workspaces no longer linger.

### 🐛 Fixes

- **ocp PowerShell arguments preserved** ([`97ffe40`](https://github.com/kenlin8827/opencode-prime/commit/97ffe40)) — user-supplied flags forwarded through the PowerShell launcher no longer get stripped on the way to the engine.
- **Installer default action invoked during upgrade** ([`2f8219c`](https://github.com/kenlin8827/opencode-prime/commit/2f8219c)) — `upgrade` now runs the installer's default action instead of no-oping when no sub-action is supplied.
