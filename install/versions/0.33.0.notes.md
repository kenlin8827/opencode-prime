## v0.33.0 — 2026-09-12

[Compare v0.32.0...v0.33.0](https://github.com/kenlin8827/opencode-prime/compare/v0.32.0...v0.33.0)

### 🎯 Highlights

- 🔍 **tgrep** — new optional search-index backend; default locate path across Lite / sidebar / project-profiler; auto-fallback to native grep/glob/rg when missing.
- 🧠 **Project-memory (phase 1)** — `/memory capture | on | off | status`; curated lessons injected alongside `AGENTS.md`.
- 🚀 **Luvus engine adapter** — `ocp tui --luvus` is now first-class alongside Herdr; bundled module + idempotent server start + herdr-recovery script.
- 🧩 **plugin-switch + system-block** — shared gate + prompt-composition infra every plugin now routes through.
- 📐 **Schema-driven wizard (phase 1)** — wizard JSON + generic renderer replaces the duplicated render / validate / persist loops.
- 🪓 **Installer split** — launcher / installer / herdr / luvus separated; per-engine manifests + recovery wiring.

---

### 🔍 tgrep — the headline feature

- **Plugin shipped** ([`f0679b3`](https://github.com/kenlin8827/opencode-prime/commit/f0679b3)) — new `plugins/tgrep/` (config, service, state, search, tool description) plus the `tgrep_search` tool surface. States surface as `OFF` / `NO CLI` / `NO WATCHER` / `STALE` / `BUILDING` / `READY` and stay observable.
- **Lite defaults to it** ([`36bf431`](https://github.com/kenlin8827/opencode-prime/commit/36bf431), [`e1058cb`](https://github.com/kenlin8827/opencode-prime/commit/e1058cb)) — `prompts/lite.md`, `prompts/code.md`, `prompts/explore.md`, `prompts/code-review.md` and `plugins/lite-tools.ts` all switch the default locate path to `tgrep_search`, with native grep/glob/rg as the explicit fallback.
- **Sidebar badge** ([`f0679b3`](https://github.com/kenlin8827/opencode-prime/commit/f0679b3), [`2cacb2e`](https://github.com/kenlin8827/opencode-prime/commit/2cacb2e)) — `plugins/tui/sidebar-status.ts` renders the live capability state next to `tgrep`, with install / start-watcher / rebuild hints that match the actual failure mode.
- **Profiler routing** ([`f0f64f2`](https://github.com/kenlin8827/opencode-prime/commit/f0f64f2), [`ba2aa7b`](https://github.com/kenlin8827/opencode-prime/commit/ba2aa7b)) — `project-profiler` composes backend routing through `plugin-switch` (tgrep / native / hybrid); capability state stays stable across rewrites via the new cache key documented in [ADR 0002](https://github.com/kenlin8827/opencode-prime/blob/main/docs/adr/0002-project-profiler-cache-key.md).
- **Benchmark + integration tests** — `scripts/benchmark-tgrep.ts` for a quick wall-clock vs ripgrep comparison; `test-tgrep-integration.ts` exercises the watcher end-to-end (`BUILDING` → `READY` → `STALE` → rebuild).

### 🧠 Project-memory (phase 1)

- **Capture + inject** ([`bbd3e43`](https://github.com/kenlin8827/opencode-prime/commit/bbd3e43)) — new `/memory capture <lesson>`, `/memory on | off`, `/memory status`. Curated, project-level lessons are injected alongside `AGENTS.md` (advisory — `AGENTS.md` wins on conflict). Manual promotion from `{draft}` to `{memory}` for now; review tooling is phase 2.
- **Plugin-scope policy** ([`eb53fda`](https://github.com/kenlin8827/opencode-prime/commit/eb53fda)) — registered in `plugin-scope.json` so Lite sessions receive the memory block by default.

### 🚀 Luvus engine adapter

- **First-class engine** ([`de0022f`](https://github.com/kenlin8827/opencode-prime/commit/de0022f)) — `ocp tui --luvus` is now a first-class workspace mode alongside Herdr. Bundled `install/luvus-modules/auto-opencode/` module is linked at install time; the Luvus server starts idempotently before a workspace opens; the explicit agent start is skipped when one is already running.
- **Herdr recovery** ([`de0022f`](https://github.com/kenlin8827/opencode-prime/commit/de0022f)) — `install/scripts/herdr-recovery.js` brings the herdr child back up when it exits non-zero; recovery is wired through the installer's engine-adapter layer.
- **Wizard parity** — `tui_mode "luvus"` is selectable in the wizard and exposed as `--luvus` in bash / PowerShell dispatchers.

### 🧩 plugin-switch + system-block (shared infra)

- **plugin-switch** ([`eb53fda`](https://github.com/kenlin8827/opencode-prime/commit/eb53fda)) — rich gate evaluation (off / contextual / forced) returning capability state; `plugins/shared/opencode-prime.ts` keeps an internal boolean alias so existing switch consumers keep compiling until they migrate.
- **system-block** ([`eb53fda`](https://github.com/kenlin8827/opencode-prime/commit/eb53fda)) — composable system-prompt fragments keyed by stable plugin id, with a fragment cache so multiple plugins injecting from the same source don't duplicate text.
- **plugin-scope.json** ([`eb53fda`](https://github.com/kenlin8827/opencode-prime/commit/eb53fda)) — registers `project-memory` and tightens `project-profiler` rules (deny utility, keep Lite + subagent coverage).

### 📐 Schema-driven wizard (phase 1)

- **JSON schemas** ([`2cacb2e`](https://github.com/kenlin8827/opencode-prime/commit/2cacb2e)) — `plugins/tui/wizard-schema/{adr,auto-advisor,project-guards,project-memory}.json` declare title, fields, validation, i18n keys.
- **Generic renderer** ([`2cacb2e`](https://github.com/kenlin8827/opencode-prime/commit/2cacb2e)) — `plugins/tui/schema-driven.ts` replaces the duplicated render / validate / persist loops in each wizard.
- **Wizards trimmed** ([`2cacb2e`](https://github.com/kenlin8827/opencode-prime/commit/2cacb2e)) — `profile-wizard.ts` / `provider-wizard.ts` / `project-wizard.ts` are now thin wrappers over `schema-driven`.

### 🪓 Installer split

- **Launcher vs installer** ([`de0022f`](https://github.com/kenlin8827/opencode-prime/commit/de0022f)) — `install/src/launcher.ts` orchestrates only; `install/src/installer.ts` owns engine selection and recovery wiring. Backwards-compatible flags.
- **Herdr / Luvus engine adapters** ([`de0022f`](https://github.com/kenlin8827/opencode-prime/commit/de0022f)) — per-engine manifests under `install/herdr-plugins/auto-opencode/` and `install/luvus-modules/auto-opencode/`; engine scripts under `install/scripts/engines/{herdr,luvus,lib}/`.
- **TUI engine extracted** ([`ca48a48`](https://github.com/kenlin8827/opencode-prime/commit/ca48a48)) — `install/src/tui-engine.ts` owns the tui-host lifecycle (start / stop / restart), key handling, busy-alert surface. `select-list`, `clipboard`, `modal` lifted into reusable UI primitives.

### 🛡 Plugin refresh

- **project-manager** ([`f0f64f2`](https://github.com/kenlin8827/opencode-prime/commit/f0f64f2)) — operations split out of `index.ts`, scaffold runs through `plugin-switch`, system-inject refreshed for project-memory + tgrep references.
- **project-profiler** ([`f0f64f2`](https://github.com/kenlin8827/opencode-prime/commit/f0f64f2)) — rewritten to compose backend routing through `plugin-switch`; cache key documented in [ADR 0002](https://github.com/kenlin8827/opencode-prime/blob/main/docs/adr/0002-project-profiler-cache-key.md).
- **guards (e2e / adr / env)** ([`6af3677`](https://github.com/kenlin8827/opencode-prime/commit/6af3677)) — internal cleanup to share the same `plugin-switch` + `system-block` primitives; on-the-wire behavior unchanged.
