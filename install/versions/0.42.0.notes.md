## v0.42.0 — 2026-09-23

[Compare v0.41.0...v0.42.0](https://github.com/kenlin8827/opencode-prime/compare/v0.41.0...v0.42.0)

### 🎯 `@build` — full capability, dispatch by default

`@build` is the all-task entry point again with **maximum capability**: full native tool surface (`task`, `read`, `edit`, `write`, `bash`, `grep`, `glob`, `webfetch`, `websearch`, `todowrite`, `skill`, `question`, `tgrep_search`, `memory_note`) and an open skill roster (`"skill": { "*": "allow" }` — git family, `/handoff`, `sdd-workflow`, `adr-*`, `clean-dead-code`, …).

What did **not** change: `prompts/build.md` keeps the multi-domain plan-first router, "default: dispatch, not do", and role walls (`@code-review` reviews, `@dba` owns schema, …). The old "never mutate / no edit-write" hard boundary is gone — capability is not the limiter; judgment is. Direct bounded work is allowed when a specialist round-trip costs more than the fix.

MCP tool surface stays hidden on build for token cost (`serena_*` / `codegraph_*` / … deny ≈ 10.9k tok/step when on).

**Permission polish (all agents):**
- lite gains `memory-summarize` skill + `memory_note` tool (matches `lite.md`).
- build / plan / code use an explicit skill roster contract; build+plan deny the full six-server MCP set including `headroom_*`; code keeps serena + CodeGraph and denies the optional servers (`gitnexus_*` / `dbhub_*` / `idea_*` / `headroom_*`). plan's tools whitelist omits `bash` (specialists run commands).
- `@dba` and `@security` keep `dbhub` visible; `@security` also keeps CodeGraph for blast-radius assessments. Coding leaves (`code`, `*-dev`, `qa`, `devops`, `fast-coder`, `explore`) deny `dbhub_*` and Scout-only `gitnexus_*` while keeping serena + CodeGraph.
- `@architect` skill roster is now explicit (`sdd-workflow` + `adr-*` only).
- Graph Scouts also drop `tgrep_search` from their native tools.

**Migration**: none required for normal use — skills that previously would not load under build now load; specialist-first workflows behave as before.

### 🔧 `lite-tools` → `tool-compress`

The description-compression plugin is renamed for what it does (compress native tool descriptions for `@lite` and `@build`). Export: `ToolCompressPlugin`. Path: `plugins/tool-compress.ts`. Tests follow the same name. Build skill prose now names the full roster.

### 📦 Installer (since v0.41.0)

- Sectioned install log + wrapper config-dir guard
- `opencode-detect` module and `@pm:` install channel
- Pin opencode to v1; lock cross-major installs (alongside the 0.41.0 major-version upgrade lock)

### 🔖 Why a minor bump

Build agent contract change (tools + skills expanded) + plugin rename — feature-level behavior change for anyone routing work through `@build`, so the minor bump applies (`DEVELOPING.md` §Adding a new skill or command, step 6).
