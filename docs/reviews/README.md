# Review Records

This directory holds compact, durable records for qualifying code reviews. Create one for L2/L3
reviews, P0/P1 findings, review-fix-loop terminal states, release/final gates, or when explicitly
requested. Do not store source excerpts, diffs, tool output, or agent transcripts here.

Routine clean L0/L1 reviews remain in the conversation. Local agent evidence belongs in `.omo/`
and is not a project record.
