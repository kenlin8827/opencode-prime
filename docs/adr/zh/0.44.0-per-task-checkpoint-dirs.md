### 01. 每任务一个检查点，而非每协议一个
**Status**: ✅ accepted

**背景**：`/dev-ultra` 写单一 `.ocp/dev-ultra-state.md`。同项目两个并行——或先后交错——的运行会互相覆盖状态，`--resume` 无法区分任务。`/dev-deep` 在 v0.43.0 带着同样的单文件设计发布，于 v0.43.1 在被广泛采用前修复（`.ocp/dev-deep/<slug>.md`）；本 ADR 将同一契约扩展到 `/dev-ultra`，并钉为未来任何可续跑协议的惯例。ADR-0.35.0#01 曾在 OCP 路径契约中钉住单文件路径 `.ocp/dev-ultra-state.md`；该行在此修订。

**决策**：

| # | 要点 | 内容 |
| --- | --- | --- |
| 1 | 布局 | 可续跑协议状态存放于 `.ocp/<protocol>/<slug>.md` —— 每任务一个文件；目录首次写入时创建，整体 git-ignore |
| 2 | slug | 从需求/目标主题派生（≤40 字符、文件系统安全、允许 Unicode —— SDD slug 惯例）；规划时公布，便于用户记录用于 `--resume=<slug>` |
| 3 | 续跑 | `--resume=<slug>` 续跑指定任务；裸 `--resume` 单检查点自动选中，多检查点在既有确认闸门处列出候选（目标、时间戳、进度）；检查点 frontmatter 携带 `slug` + `status`（`running \| stopped \| completed`） |
| 4 | 守卫 | 同 slug 未完成检查点且未带 `--resume` → 运行前提问（续跑/覆盖/中止）；已完成的检查点覆盖前告知 |
| 5 | 旧文件 | 续跑回退**在 v2 移除**（大版本线切割；v1 线保留）——旧单文件在 v2 既不迁移也不 git-ignore；遗留在工作区的旧文件是死数据，用户可自行删除 |
| 6 | gitignore 契约 | `ensureOcpGitignore` 引导内容增至八行（新增 `dev-ultra/`，v2 同时移除旧 `dev-ultra-state.md` 行）；heal 为既有项目追加目录条目 |

**理由**：

- **并行运行是合法场景** —— 协议本身不禁止多目标在跑，状态布局也不该禁止
- **目录优于后缀文件** —— `.ocp/<protocol>/` 一行即可 gitignore，且为未来每运行制品留位，无需再改契约
- **守卫优于文件锁** —— 提示词层协议没有文件锁原语；显式运行前提问是可执行的等价物
- **一套惯例、两个协议** —— dev-deep 与 dev-ultra 共享 slug/续跑/守卫语义，用户学一次即可

**被否方案**：

| 选项 | 否决理由 |
| --- | --- |
| 保留单文件＋运行时锁 | 提示词层协议无锁原语；"锁"只是模型可无视的建议文本 |
| 时间戳后缀文件（`state-<ts>.md`） | 任务身份不可读；`--resume` 终究要列表才能瞄准；slug 自带语义 |
| 状态并入 `.ocp/ocp.json` | 状态是 markdown 文档（阶段摘要、结论），不是配置；塞进 JSON 两头难读 |
| 就地修改 ADR-0.35.0 | 已接受记录只能经新记录申诉修订（ADR-0.40.3）；修订落在本文件 |

**影响**：

- **技能** —— `skills/dev-ultra/SKILL.md`（Arguments、Resume check、Step 4 压缩与格式、Session recovery、Guardrail 8）；`skills/dev-deep/SKILL.md` 自 v0.43.1 已合规
- **插件** —— `plugins/shared/opencode-prime.ts`：`ensureOcpGitignore` 引导 7→8 行（新增 `dev-ultra/`，v2 移除 `dev-ultra-state.md`）＋`dev-ultra/` heal 分支；旧迁移列表移除 `dev-ultra-state.md`（v2 无读取方——v1 线保留迁移与回退两者）
- **测试** —— `test-project-memory-unit.ts` 引导 pin（八行）＋heal 断言
- **文档** —— `docs/workflows/dev-loops.md` ＋中文镜像（Resume 行）；`commands/dev-ultra.md` usage 串
- **ADR** —— 修订 ADR-0.35.0#01 制品表第 4 行；`INDEX.md` 待工具再生成（生成文件，不由手工编辑）
